# Security policy

ChangePack365 is designed to package evidence, not to grant permissions or bypass tenant controls.

- Never commit tenant exports, tokens, secrets, recovery keys, UPNs, or production evidence.
- Use the fictional data under `examples/` for demonstrations.
- Run write operations only with an approved change and least-privileged identity.
- Treat internal bundles as confidential. Public bundles are a convenience, not a substitute for human review.
- Report vulnerabilities privately through GitHub Security Advisories.

Supported versions: the latest tagged release only.
